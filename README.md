# SPAM Deck Lab

Logiciel Windows qui trouve tes meilleurs decks **SPAM** avec les cartes que tu possèdes, en faisant jouer des
milliers de parties par l'IA du jeu, sur ton PC et hors ligne.

- Coche tes cartes et tes talents, tout reste enregistré sur ton PC (pas de compte).
- Teste un deck contre les decks forts du jeu, ou laisse le logiciel chercher tes meilleurs decks, dans le bon ordre de placement.
- Rôle de chaque carte, qui booste qui, statistiques, et patch notes détaillés (avant → après) à chaque mise à jour de SPAM.
- Le logiciel se met à jour tout seul.

## Installer

1. Télécharge **`SPAM-Deck-Lab-Setup-….exe`** dans la [dernière version](https://github.com/NostaliumEu/spam-deck-lab/releases/latest).
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur » (le setup n'est pas signé) :
   clique sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Ouvre **SPAM Deck Lab** depuis le bureau ou le menu Démarrer.

Il faut **Windows 10 ou 11** et **SPAM installé avec Steam**. Au premier lancement, le logiciel fait sa propre copie
du jeu (environ 2,6 Go) pour simuler des parties : ton jeu Steam n'est jamais modifié, rien ne se joue en ligne
et aucun bot n'affronte de vrais joueurs.

Pour le désinstaller : Paramètres Windows → Applications → SPAM Deck Lab.
